# Afana Labs Website

A premium, fully responsive dark-mode website for Afana Labs and Phantom Depth Studio.

## Features

- Futuristic luxury dark theme with glassmorphism effects
- Neon blue and purple glow accents
- Insomniac Games-style scroll reveal animations
- Fully responsive design
- Cinematic, immersive user experience

## Sections

1. Hero Landing - Animated background with logo and CTAs
2. About Afana Labs - Studio overview
3. Applications Gallery - App previews
4. Phantom Depth Studio - Game division showcase
5. Space White - In-development game details
6. eBooks & Digital Guides - Book showcases
7. Studio News & Updates - Latest announcements
8. Contact & Collaboration - Business links

## Technologies Used

- HTML5
- CSS3 (with glassmorphism and animations)
- JavaScript (Intersection Observer for scroll effects)

## Running the Site

Open `index.html` in a modern web browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`

## Customization

- Replace placeholder images with actual assets
- Update content in `index.html`
- Adjust colors and effects in `styles.css`
- Modify animations in `script.js`
